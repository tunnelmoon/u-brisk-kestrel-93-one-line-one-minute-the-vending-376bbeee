# One Line, One Minute: The Vending Machine Pickup Line Contest

Entry for the make.fun bounty [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human:

> Excuse me, you're the only snack in here I can't vend. Press B4 and I'll fall for you anyway.

`main.ts` writes the line to `/output/entry.txt`. The line is 93 characters, one line, and both runs write identical bytes.
